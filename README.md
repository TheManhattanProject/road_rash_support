## 🚀 GitHub Repository & Pages Setup

### 1. Create the GitHub Repository
1. Go to GitHub and create a new public repository named:
   ```text
   road_rash_support
   ```
   *(e.g., `https://github.com/TheManhattanProject/road_rash_support`)*

2. In this folder (`/Users/sarthakbansal/Desktop/road_rash_support`), link the remote and push:
   ```bash
   git remote add origin https://github.com/TheManhattanProject/road_rash_support.git
   git branch -M main
   git push -u origin main
   ```

### 2. Enable GitHub Pages
1. Go to your repository on GitHub: **Settings > Pages**
2. Under **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`
   - **Folder**: `/ (root)`
3. Click **Save**.
4. Within 1–2 minutes, your support website will be live at:
   ```text
   https://themanhattanproject.github.io/road_rash_support/
   ```
